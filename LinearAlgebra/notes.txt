### Vectors ###

    1. Point in a 2D/3D etc co ordinate system is represented in form of vector 
    Point in a particular co ordinate system
        eg: a=[2,3], b=[2,3,4]
        2 and 3 | 2 and 3 and 4 are called as components of the vector

    2. Dimension: Vector in nD co ordinate system has a dimension of n
    3. Used as a feature vector in ML 
    4. Vectors are usually represented as numbers

    Eg: Used in recommender system

    # Row Vector: Vector represented in the form of row (1 x n)
    # Coloum Vector: Vector represented in the form of column (n x 1) 

    # Distance from the origin/Magnitude
        A = [x,y]
        ||A|| = distance from origin = sqrt(x^2 + y^2)

        B = [x,y,z]
        ||B|| = distance from origin = sqrt(x^2 + y^2 + z^2)

        C = [a,b,c,...]
        ||C|| = distance from origin = sqrt(a^2 + b^2 + c^2 + ...)

    # Euclidean Distance
        In 2D space
        [a,b] and [c,d]
        distance = sqrt(((c-a)^2) + ((d-b)^2))

        In 3D space
        [x1,y1,z1] and [x2,y2,z2]
        distance = sqrt((x2-x1)^2 + (y2-y2)^2 + (z2-z1)^2)

        Used in k-nearest algorithm

    # Scalar Addition and Scalar Subtraction - this shifts the vector in the co-ordinate system and hence called as SHIFTING

        V = [v1,v2,v3,..,vn]
        scalar = n 
        Scalar Addition = V + scalar = [v1+n,v2+5,v3+5,...]
        Scalar Subtraction = V - scalar = [v1-n,v2-5,v3-5,...]

        Used in mean centering - PCA, linear regression, clustering, regularisation etc

    # Multiplication: 
        1. Dot Product / Scalar Product
        2. Cross Product / Vector Product

    # Dot Product
        A = [a1,a2,a3,...,an] nx1 - column
        B = [b1,b2,b3,...,bn] nx1 - column
        Component wise product and sum of all = a1b1 + a2b2 + a3b3

        AT x B (A transpose x B) = A.B
        Result is a SCALAR VALUE

        Dot product is commutative : A.B = B.A
        Dot product is distributive: A.(B+C) = A.B + B.C

        1. Used to compute similarity between 2 vectors
        2. Used to calculate projections
        3. Used to perform matrix multiplication
        4. Used in Deep Learning
    
    # Angle between 2 vectors

        A and B are vectors, angle between them is theta
        (dot product) A.B = ||A|| ||B|| cos(theta)

        * if, A and B are not zero and A.B = 0, hence, ||A|| ||B|| cos(theta) = 0
        means, angle between then is 90 (perpendicular)
        * helps to calculate the angle between the two vectors 

    # COSINE SIMILARITY 

        cos(theta) = A.B / (||A|| ||B||)
        This is the angle between 2 vectors 
        Used as similarity measure

        if cos(theta) = 1; theta = 0; then both vectors are similar(same direction)
        if cos(theta) = -1; theta = 180; then both vectors are disimilar(opposite direction)
        if cos(theta) = 0; theta = 90; no similarity between the vectors

    # Hyperplane
        * Helps for representing multidimensional data 

        * 2D - equation of a line
            equation: y=mx+b

            equation:   ax+by+c = 0
                        y = (-a/b)x + (-c/b)
                        therefore, m= -a/b, b= -c/b

            equation:   w1x1 + w2x2 + w0 = 0
                        WT * X + w0 = 0

        * 3D - equation of a plane 
            equation:   w1x1 + w2x2 + w3x3 + w0 = 0
                        WT * X + w0 = 0

        * nD - equation of a hyperplane of n dimension
            equation:   w1x1 + w2x2 + w3x3 + ... + wnxn + w0 = 0
                        W = [w1,w2,w3,...,wn]
                        X = [x1,x2,x3,...,xn]

                        WT * X + w0 = 0

            If the hyperplane passes through origin, then
            WT * X = 0

            W.X = ||W|| ||X|| cos(theta) = 0
            theta = 90 degree

            W and X are 90 degree apart
            W is perpendicular to the hyperplane


### Matrices ###
    * Matrix are the rectangular array of numbers arranged in the form of rows and columns
    * Order of the matrix : number of rows * number of columns 

    Applications:
        1. Linear system of equations: Eg- 5x+3y=6
        2. Linear Transformation
        3. Eigen Values and eigen vectors 
        4. Graph theory
        5. Markov chain
        6. Graphics
        7. Optimisation
    
    Types of Matrices:
        1. Normal matrix
        2. Row matrix / Row vector : Only one row
        3. Column matrix : Only one column 
        4. Square matrix : 
            * number of columns = number of rows
            * for diagonal elements, row number = column number

        5. Diagonal matrix : 
            * Square matrix
            * non diagonal elements are zero
        
        6. Scalar matrix :
            * diagonal matrix
            * all diagonal items are equal
        
        7. Identity matrix
            * Scalar matrix
            * diagonal element value = 1

        8. Zero matrix : All elements are zero

        9. Singular matrix: Those square matrix whose determinant is ZERO 

    # When are 2 matrix, A and B, equal?
        * Order should be same
        * Aij = Bij

    # Scalar Operations : Addition and Multiplication
        * Scalar addition: Scalar value get added to all the elements of the matrix
        * Scalar Multiplication: Scalar value get multiplied to all the elements of the matrix
            Eg: multiplying a matrix with -1 gives the nagative of the matrix
            A * -1 = -A

        * scalarValue = k
        k (A + B) = kA + kB 

    # Matrix Addition, Subtraction
        * Addition
            - Order should be same
            - Element wise addition will occur

        * Subtraction
            - Order should be same
            - A + (-1 * B)

        * A + B = B + A
        * A+(B+C) = (A+B)+C

        * Additive Identity: 
            - Adding a matrix to A to give a
            - A + X = A
            - X is a zero matrix 
    
        * Additive inverse:
            - A - X = 0
            - X is negative of A
            * Additive inverse is the negative of the matrix

    # Matrix Multiplication
        * It is baiscally a dot product and not element wise multiplication
        * Columns of 1st matrix should be same as the rows of the second matrix, that is, A: x*y and B: y*z
        * Shape of the resultant matrix = x*z

        Rules:
            1. AB != BA
            2. (AB)C = A(BC)
            3. A(B+C) = AB + AC 
        
        Multiplicative Identity:
            * A x X = A
            * X is the Identity Matrix of the same order
            * For this A should be a square matrix

    # Transpose of a matrix
        * Converting the rows into columns and columns to rows 
        * If A: x*y, then A(T): y*x

        * Symmetric matrix:
            A = A(T)
            Transpose of a matrix gives the matrix itself

        * Skew Symmetric matrix:
            A(T) = -A
            Transpose of a matrix gives the negative of the matrix

        * Rules
            1. Transpose of A(T) gives A
            2. (A+B)T = AT + BT
            3. (AB)T = BT . AT 

    # Inverse of a matrix 
        * An inverse matrix is a matrix when multiplied by the original matrix results in the identity matrix
        * AxA(inverse) = I

        if AX = B,
        then X = B/A            --> Matrix division is not possible
        therefore, X = B A(inverse)

        * Not all matrices are invertible
        * Only few square matrix are invertible
        * Determinant of the square matrix should not be ZERO, it should be non singular.
        
            Then, 
            A(inverse) = Adjoint(A)/determinat(A)

        * To find adjoint we need determinant, minor, co-factor

    # Determinant
        * It is a scalar value
        * Applicable only for square matrix

        * Uses:
            - invertibility of a matrix
            - finding solutions to systems of linear equations
            - calculating the volume scaling factor for linear transformation

    # Minor 
        * Minor of an element aij of a determinant is the determinant obtained by deleting the row and column where it is present. It is denoted by Mij

    # Co-Factor
        * Co-Factor of an element is defined by 
        Aij = -1^(i+j) Mij
            Eg, A23 = (-1)^5 + M23 

        * Sum of the product of elements of any row (or column) with their corresponding co-factors gives determinant
            Eg: A11a11 + A12a12 + A13a13

    # Adjoint/Adjugate/Classical Adjoint
        * Replace each item with co-factor and take the transpose of the matrix

    # Finding the values in linear algebra
        A X = B   
        X = A(inverse) . B
